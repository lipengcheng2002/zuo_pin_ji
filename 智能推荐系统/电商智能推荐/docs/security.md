# 安全与隐私 · ZHIYAN

## 1. 资产与信任边界

| 资产 | 位置 | 风险 |
| --- | --- | --- |
| 订单/地址/手机号 | 服务端存储 | 泄漏、越权读取 |
| 画像与行为 | 服务端 + 内存 | 隐私、画像歧视 |
| 运维观测面 | `/api/health`、`/api/metrics`、`/api/agent/capabilities` | 版本/经营信息暴露；网关需限制 |
| LLM Key | 环境变量 | 泄漏、成本滥用 |
| Agent 工具 | 服务端 | 提示词注入、越权写入 |
| 运行指标 | `/api/metrics` | 暴露经营数据 |

信任边界：

- 浏览器输入一律不可信
- 模型输出（含 LLM）一律不可信，需护栏校验
- 外部 LLM 属于第三方处理者，启用前必须评估数据协议

## 2. 身份与会话

### 商城会话

- `zy_sid`：HttpOnly、SameSite=Lax、生产 Secure、180 天
- 匿名会话用于购物袋、对话与心愿单；演示环境固定使用主用户画像
- 会员登录新增 `zy_customer`：HttpOnly、SameSite=Lax、生产 Secure、30 天；服务端只保存令牌 SHA-256 哈希，退出即撤销
- 演示模式 `DEMO_AUTH=true`：微信授权为模拟、手机验证码回显固定码 `246810`（可用 `DEMO_OTP_CODE` 覆盖），**只适用于本地演示**
- 真实微信 OAuth：`/api/auth/wechat/start` 生成随机 state 并用 `WECHAT_APP_SECRET` 做 HMAC，写入 10 分钟 HttpOnly Cookie；回调同时校验 query state 与签名后才换取 `openid`，防止 CSRF/重放
- 回调地址必须是微信开放平台登记的公网 HTTPS 域名；OAuth 失败只回跳登录页，不记录 code/secret
- 生产需接入微信开放平台 OAuth 与短信供应商，设置 `DEMO_AUTH=false`；验证码 5 分钟有效、5 次尝试上限、手机号 30 秒发送冷却
- 当前演示登录身份与主演示会员档案绑定；真实会员体系需将 `userId` 绑定到客户记录并隔离购物袋/订单

### 管理端与平台运维面

- `/admin` 是独立管理端（不进入用户端导航）；使用 `AGENT_ADMIN_TOKEN` 登录，服务端签发 HMAC 签名 `zy_admin` Cookie（HttpOnly / SameSite=Lax / 生产 Secure / 8h）
- 管理 API 同时接受该 Cookie 或 `Authorization: Bearer $AGENT_ADMIN_TOKEN`；未配置 Token 时全部 503
- 管理端只做 Agent Registry（草稿、上架/下架、版本、回滚、Key），不是订单/库存后台
- `/api/health`、`/api/metrics`、`/api/agent/capabilities` 建议只在受信网关/VPC 内暴露
- `/api/ops/orders` 使用 `OPS_TOKEN` Bearer 鉴权，仅供 OMS/平台内网调用；未配置时关闭
- 审计事件仍由后端写入，供平台/SIEM 读取
- 生产建议：管理端走 VPN/内网/网关鉴权，后续接入 SSO/MFA 与多操作员 RBAC

## 3. 请求防护

| 控制 | 实现 |
| --- | --- |
| 同源校验 | 写接口检查 `Sec-Fetch-Site`、`Origin` 与 Host（`src/lib/security.ts`） |
| 限流 | 进程内固定窗口：会员验证码 8/min/IP + 1/30s/手机号、会员登录 12/min、Agent 24/min、下单 12/min、事件 180/min；429 返回 `Retry-After` |
| 大小限制 | Next 默认 + Nginx 2 MB |
| 输入校验 | Zod：购物袋、订单、画像、事件与会员登录 |
| Cookie | HttpOnly + SameSite + Secure |
| 响应头 | CSP、X-Frame-Options、nosniff、Referrer-Policy、Permissions-Policy |
| 缓存 | `/api/*` 强制 `no-store`；页面动态渲染 |

多副本部署时，进程内限流会失效；应在网关（Nginx/云 WAF）配置第二层限流，或将计数迁移 Redis。

## 4. Agent 安全

### 4.1 提示词注入

- 规则检测中英文越权指令（忽略指令、输出系统提示、开发者模式、泄露密钥等）
- 命中后不调用工具，返回固定业务范围回答
- LLM 规划只允许白名单工具；参数被截断、类型过滤
- 不把页面/商品描述中的文本当作指令执行

### 4.2 写入型工具

`add_to_cart` 与 `update_preference` 只有在用户消息明确包含「加购/加入购物袋/下单/记住/更新偏好」等指令时才执行。
LLM 规划器无法自行发起写入。

### 4.3 输出护栏

| 检查 | 行为 |
| --- | --- |
| 提示词注入 | 阻断 |
| 价格事实 | 回答中价格必须来自商品/购物袋/订单/预算上下文 |
| 库存声明 | 「有货/现货」须有 SKU 库存支持 |
| 尺码免责 | 自动补充“仅供参考，建议试穿” |
| 政策引用 | 售后回答必须命中知识库，否则建议转人工 |
| 促销一致性 | 折扣/优惠券必须与当前配置一致 |
| 绝对化/功效用语 | 移除或补充合规提示 |
| 工具预算 | 超限则阻止 |
| 置信度 | 低于阈值提示补充信息 |
| AI 透明度 | 理由标注来源与置信度 |

### 4.4 LLM 模式

- 仅发送必要的画像摘要、商品事实与知识片段
- 超时 9s 自动回退本地；提示词与温度可配置
- LLM 输出会再次经过价格校验；失败即回退初稿
- API Key 只从环境变量/密钥管理服务读取，不进入仓库、镜像、日志或前端 bundle
- 模型网关可通过 `LLM_BASE_URL`、`LLM_MODEL` 与 Key 轮换；`AGENT_ENABLED=false` 可熔断对话
- 生产需增加：内容审核、PII 出站网关、供应商数据保留设置、成本配额与熔断

## 5. 隐私

### 收集

- 演示数据为合成；账户页面展示的画像与行为用于演示
- 真实部署应只收集完成服务所必需的数据，并提供关闭个性化选项

### 使用

- 画像用于召回、排序、尺码与理由
- 不用于模型训练（当前 LLM 模式仅推理）
- 不出售；不用于第三方广告

### 保留

| 数据 | 上限/策略 |
| --- | --- |
| 运行时事件 | 5,000 条 |
| 会话消息 | 每会话 60 条 |
| Agent 日志 | 500 条 |
| 购物袋/订单 | 持久化，直到删除或重置 |

### 用户权利

- 账户内可修改风格、尺码、预算与场景
- 生产应提供：导出、删除、撤回个性化同意
- 日志中手机号/身份证/邮箱在写入前掩码

## 6. 数据存储安全

- 文件驱动：容器内 `/data`，建议加密卷与最小权限
- PostgreSQL：独立账号、最小权限、TLS（`PGSSL=true`）、备份加密
- 密钥只在环境变量/Secret 管理器，不入库、不入镜像
- 备份包含个人信息，需访问控制与保留期限

## 7. 依赖与供应链

- 锁定版本（`package-lock.json`），CI 使用 `npm ci`
- 生产镜像使用多阶段构建、非 root 用户、最小基础镜像
- 建议启用 `npm audit`/Dependabot 与镜像扫描（Trivy/Grype）
- 离线 ML 依赖（torch/spark）建议在隔离镜像构建，不进入 Web 运行镜像

## 8. 已知限制

1. 管理端目前是单 `AGENT_ADMIN_TOKEN`，未实现多操作员 RBAC/审批流；生产需接入 SSO/VPN 与审计归档
2. 限流为单进程；多副本需网关/Redis
3. CSP 允许内联脚本（Next 运行时需要）；更严格部署可改为 nonce 方案
4. 演示登录映射到同一演示会员档案，未验证真实多用户数据隔离
5. 商品/订单/物流均为模拟；不可用于真实交易
6. 文件存储单写者；结算互斥为进程内，多实例前需数据库拆表、事务与行锁
7. 库存采用订单承诺模型，不对商品基础档案做持久扣减

## 9. 安全响应

发现漏洞请勿公开披露。生产环境应建立：

- 安全邮箱与 48 小时响应承诺
- 严重漏洞的紧急回滚流程（见 `docs/runbook.md`）
- 密钥泄漏的轮换清单
- 事件记录：发现时间、影响、根因、修复、复盘
