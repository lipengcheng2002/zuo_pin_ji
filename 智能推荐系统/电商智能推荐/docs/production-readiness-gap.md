## 3. P2：规模化再补

- 向量库/ANN（pgvector/Milvus/FAISS）与商品知识增量索引。
- Kafka/Redis Streams 实时事件、Flink/Spark Streaming 特征、Redis 特征库。
- 多租户 `tenant_id`、平台 SSO、审批流、灰度发布平台。
- 自研/托管模型网关、供应商多活、推理缓存、Token 计量。
- 离线训练→ONNX 在线排序、实验平台与自动显著性。

## 4. 已经具备、可复用的企业级能力

- 移动端底部导航、个人中心、画像“降层”展示。
- 会员服务端会话（HttpOnly + SHA-256 + 30 天）、验证码限流/冷却/尝试上限。
- 微信 OAuth state HMAC 防 CSRF；真实跳转链路已可配置。
- Agent Registry：草稿、上架/下架、不可变版本、回滚、调用 Key（哈希/过期/撤销）与生命周期审计。
- Agent 11 工具、白名单、写入型工具明确指令门槛、价格/库存/政策/尺码护栏。
- SSE `meta/stage/trace/.../done/error`、8 秒心跳、requestId 贯穿 trace 与 done。
- `/api/agent/capabilities`、`checks.agent`、`zhiyan_agent_*` 指标。
- Agent 评测：33 意图、13 槽位、10 检索、15 注入、0 误伤。
- 结算幂等键、库存承诺、取消/退货释放、审计后端。
- Docker/Compose/Nginx/CI 参考模板与部署文档。
